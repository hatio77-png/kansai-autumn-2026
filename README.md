# 關西秋楓 2026｜電子旅遊書

## GitHub Pages 發布方法
1. 在 GitHub 建立公開儲存庫（例如 `kansai-autumn-2026`）。
2. 解壓縮 ZIP，將 `index.html` 和 `.nojekyll` 上傳至儲存庫最外層。
3. 前往 Settings → Pages → Build and deployment：Source 設為 Deploy from a branch，Branch 設定 `main`，資料夾選 `/(root)`，按 Save。
4. 網站網址通常為 `https://使用者名稱.github.io/kansai-autumn-2026/`。

注意：此網站是公開網址。請先確認公開航班時間、座位及飯店資訊是否合適。勾選清單只會儲存在每個人的瀏覽器，不會跨裝置同步。天氣需網路。
